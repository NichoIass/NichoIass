# Provision Tool - Enterprise SSH Deployment Utility

**Современное десктопное приложение для параллельного прошивки и конфигурации устройств по SSH.**

## 🎯 Возможности

- ✅ Параллельное подключение и прошивка множества устройств
- ✅ Автоматическое заполнение колонок IP адресов и хостнеймов
- ✅ Мониторинг перезагрузки устройств в реальном времени
- ✅ Логирование всех операций
- ✅ Сохранение сессии и восстановление данных
- ✅ Поддержка SSH ключей и паролей
- ✅ Резервный логин/пароль для SSH подключения
- ✅ Проверка доступности устройств после прошивки
- ✅ Экспорт отчётов в CSV
- ✅ Тёмный современный интерфейс WPF
- ✅ Асинхронная обработка операций

## 🔧 Требования

- Windows 7+ или Windows Server 2012+
- .NET Framework 4.7.2+ или .NET 6+
- Visual Studio 2019+ (для разработки)

## 📦 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/NichoIass/NichoIass.git
cd NichoIass

# Открыть в Visual Studio
start ProvisionTool.sln

# Собрать проект
MSBuild ProvisionTool.sln /p:Configuration=Release
```

## 🚀 Использование

1. Введите SSH учётные данные (основные и резервные)
2. Заполните таблицу с IP адресами и хостнеймами
3. Используйте кнопку "Автозаполнение" для быстрого заполнения колонок
4. Нажмите "Запустить всё" или выберите строки и нажмите "Запустить выбранное"
5. Мониторьте прогресс в реальном времени
6. Проверьте отчёт после завершения
